# News Explorer - Frontend

Aplicación React para buscar y guardar artículos de noticias usando News API.

## 🚀 Tecnologías

- React 18
- Vite
- React Router
- News API

## 📦 Instalación

```bash
npm install
```

## 🔧 Desarrollo

```bash
npm run dev
```

## 🏗️ Build

```bash
npm run build
```
